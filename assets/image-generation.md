# Assets

- `stonkfly.png` — the header illustration, inherited from
  [nftechie/stonkfly](https://github.com/nftechie/stonkfly). Generated with an image
  generation tool. The chart in it is decorative concept art, not a trading result.
- `site.png` — a screenshot of `python -m stonkflyrh serve` rendered against a local
  paper run driven by the offline fixture market. The trades, prices and wallet
  addresses in it are simulated; it shows what the page looks like, not a real result.
